# Product Learning Journal

**Author:** Karani Njoroge
**Purpose:** Weekly reflections on PM concepts, frameworks, products, and lessons — learning in public.

---

## Why I Write This

Writing forces clarity. A PM who cannot explain a concept simply has not understood it deeply enough.

This journal is not a summary service. It is a processing tool. Every entry takes something I encountered — a framework, a product, a conversation, a book — and works out what it actually means for how I build and think.

I publish it publicly because learning in isolation is slower than learning in conversation.
